# 04 — Graph ontology (v0.1.0)

The ontology is specific to this study. It is intentionally small, typed and provenance-first. It is **not** a general biomedical upper ontology and does not claim OWL-level formal semantics.

---

## 1. Design principles

1. **No generic `associated_with`.** Every edge states the nature of the relation.
2. **Evidence is a first-class table**, not an edge attribute: one relation can have many evidence rows.
3. **Layers are explicit**: observed, structured, inferred, hypothesis, ecological.
4. **Identifiers are stable and external where possible** (PMID, ClinVar accession, Reactome stId, HPO ID, CID-10, NCBI Gene ID).
5. **No edge without a source.** `HYPOTHESIS_LINK` edges are allowed only in the hypothesis layer and have no empirical reference.

---

## 2. Node types

| Type | Definition | ID pattern | Required attributes | Examples |
|---|---|---|---|---|
| `Exposure` | Class-level environmental, occupational, behavioural or therapeutic exposure | `EXP:<ABBR>` | label, class, local_relevance | `EXP:PM25`, `EXP:VPA` |
| `Chemical` | Reserved for individual chemical agents (not used in v0.1.0; exposures are class-level) | `CHEM:<id>` | — | — |
| `ClimateVariable` | Reserved for specific meteorological variables as nodes (currently represented as `Indicator`) | `CLIM:<id>` | — | — |
| `Mechanism` | Molecular/cellular mechanism potentially perturbed by an exposure | `MECH:<ABBR>` | label | `MECH:OXSTRESS` |
| `Gene` | Human gene | `GENE:<symbol>` | NCBI Gene ID where available | `GENE:NKX2-5` |
| `Pathway` | Reactome pathway | `PATH:<stId>` | Reactome stId | `PATH:R-HSA-9733709` |
| `Process` | Embryonic/cardiac developmental process | `PROC:<ABBR>` | label | `PROC:OFT` |
| `Phenotype` | CHD phenotype, study vocabulary + CID-10 + HPO | `CHD:<ABBR>` or `CHD:ALL` | CID-10, HPO (where available) | `CHD:VSD` |
| `Variant` | ClinVar variant (pathogenic/likely pathogenic) | `VAR:<VCV accession>` | cDNA change, classification | `VAR:VCV005018655` |
| `Indicator` | Ecological/epidemiological indicator derived from local data | `IND:<NAME>` | system, definition | `IND:SINASC_CHD` |
| `Population` | Study population | `POP:<NAME>` | geographic identifier | `POP:CAMPOS` |
| `Period` | Temporal scope | `PERIOD:<range>` | start/end | `PERIOD:2010-2025` |
| `Study` | Reserved for study nodes (v0.1.0 uses evidence rows with PMID instead) | `PMID:<id>` | — | — |
| `DataSource` | Reserved for source nodes | `SRC:<name>` | — | — |

`Chemical`, `ClimateVariable`, `Study` and `DataSource` are declared but not instantiated in v0.1.0. This is documented rather than silently ignored.

## 3. Relation types

| Relation | Domain → Range | Meaning | Empirical requirement |
|---|---|---|---|
| `EXPOSURE_ASSOCIATED_WITH_PHENOTYPE` | Exposure → Phenotype | Human study reports an association between the exposure and the phenotype | human epidemiological design |
| `EXPOSURE_MODULATES_MECHANISM` | Exposure → Mechanism | Exposure changes the mechanism in a measured system | human biomarker, animal or cell experiment |
| `MECHANISM_INTERFERES_WITH_PROCESS` | Mechanism → Process | Perturbation of the mechanism alters the developmental process | experiment or review of experiments |
| `GENE_ASSOCIATED_WITH_PHENOTYPE` | Gene → Phenotype | Variant/gene is associated with the phenotype | human genetics or curated annotation |
| `GENE_PARTICIPATES_IN_PATHWAY` | Gene → Pathway | Gene product participates in the pathway | Reactome annotation |
| `PATHWAY_REGULATES_PROCESS` | Pathway → Process | Pathway is mapped to a developmental process | **inferred** (keyword mapping) |
| `VARIANT_IN_GENE` | Variant → Gene | Variant lies in / is annotated to the gene | ClinVar |
| `ALTERATION_ASSOCIATED_WITH_PHENOTYPE` | Process or Variant → Phenotype | Alteration of the process (or a variant) is associated with the phenotype | review/annotation |
| `INDICATOR_DESCRIBES_PHENOTYPE` | Indicator → Phenotype | Local indicator measures the phenotype | administrative data |
| `ECOLOGICAL_CONTEXT_FOR` | Exposure/Indicator → Population/Indicator | Area-level context relation; explicitly not individual exposure | ecological data |
| `HYPOTHESIS_LINK` | Exposure → Process | Plausible link generated by composing observed edges; never tested directly | **none** (by definition) |
| `STUDY_DOCUMENTS_RELATION` | Study → Relation | Reserved; v0.1.0 records studies in the evidence table instead | — |

`PROCESS_ORIGINATES_STRUCTURE` is declared in the enumeration for future anatomical-structure nodes but is not used in v0.1.0.

## 4. Evidence row schema (the provenance unit)

File: `outputs/graph/evidence.csv`.

| Field | Meaning |
|---|---|
| `evidence_id` | SHA-1 of edge key + reference + evidence type + population |
| `edge_key` | `source|relation|target` |
| `source_id`, `source_type` | origin node |
| `target_id`, `target_type` | destination node |
| `relation` | one of the typed relations |
| `layer` | `observed`, `structured`, `inferred`, `hypothesis`, `ecological` |
| `evidence_type` | `direct_human`, `experimental_human`, `experimental_animal`, `experimental_cell`, `structured_database`, `indirect`, `hypothesis` |
| `study_design` | cohort, case_control, meta_analysis, registry, cross_sectional, ecological, animal_in_vivo, in_vitro, in_silico, narrative_review, curated_database, unknown |
| `species` | human, mouse, rat, zebrafish, chick, xenopus, Atlantic sturgeon, or `;`-joined |
| `population_or_model` | free text (e.g. “704,209 fetuses, Quebec 1988–2012”) |
| `exposure_window` | e.g. “weeks 2–8 postconception” |
| `effect_direction` | textual + estimate + CI where available |
| `context` | exposure/assay context |
| `quote` | verbatim abstract fragment (curated rows only) |
| `reference` | PMID, ClinVar accession, Reactome stId, HPO disease ID |
| `reference_type` | PMID, ClinVar accession, Reactome pathway, HPO annotation, health information system, reanalysis dataset, rule |
| `source_database` | PubMed (manual curation), HPO, ClinVar, Reactome, DATASUS, Open-Meteo |
| `retrieved_at` | ISO date |
| `notes` | limitations, caveats, layer-specific warnings |

## 5. Layers and permitted reasoning

| Layer | Definition | Used in path analysis? | Used in centrality? |
|---|---|---|---|
| `observed` | Relation directly documented in a retrieved source (manual curation) | Yes | Yes |
| `structured` | Curated database annotation (HPO, ClinVar, Reactome) | Yes (gene/pathway subgraph) | Yes (variants excluded) |
| `inferred` | Derived by an explicit, documented rule (pathway→process keyword map) | Yes, flagged | Yes, flagged |
| `hypothesis` | Plausible composition of observed edges, not directly tested | **No** | **No** |
| `ecological` | Local aggregate context (indicator, area-level exposure) | **No** (reported separately) | **No** |

`HYPOTHESIS_LINK` edges are generated only when an exposure→mechanism and a mechanism→process edge exist and no direct exposure→process evidence was retained. They are counted in `outputs/tables/gap_analysis.csv`, not in `paths_exposure_phenotype.csv`.

---

## 6. Inference rules (documented, minimal)

1. **Hypothesis composition** (layer `hypothesis`):
   `EXPOSURE_MODULATES_MECHANISM(x,m)` ∧ `MECHANISM_INTERFERES_WITH_PROCESS(m,p)` ∧ ¬direct(x,p) ⇒ `HYPOTHESIS_LINK(x,p)`.
2. **Pathway→process keyword map** (layer `inferred`):
   Reactome pathway names are matched to process keywords (`heart tube`, `looping`, `sept`, `valve`, `cushion`, `outflow`, `neural crest`, `chamber`, `cardiomyocyte`, `conduction`, `coronary`, `angiogen`, `vascul`, `endotheli`). The mapping table is exported (`data_processed/inferred_pathway_process_map.csv`). It is a heuristic and is labelled as such.
3. **No transitive closure is stored as observed.** Only the two rules above create non-observed edges, and both are labelled.

## 7. Example subgraph

```
EXP:HEAT --EXPOSURE_MODULATES_MECHANISM--> MECH:NEURAL_CREST
         (PMID 29018170; chick/zebrafish; experimental_animal; C)

MECH:NEURAL_CREST --MECHANISM_INTERFERES_WITH_PROCESS--> PROC:OFT
         (PMID 32071091; review of chick/mouse; indirect; D)

PROC:OFT --ALTERATION_ASSOCIATED_WITH_PHENOTYPE--> CHD:TOF
         (PMID 24014420; review; indirect; D)

⇒ path EXP:HEAT → MECH:NEURAL_CREST → PROC:OFT → CHD:TOF
   path confidence = min(0.585, 0.440, 0.440) = 0.440 (D)
```

The direct human edge `EXP:HEAT → CHD:ASD` (PMID 27494594) is grade A and is **not** evidence for the TOF path. Path confidence is the minimum edge confidence, so a chain is never stronger than its weakest link.

## 8. Entity-resolution rules

- Genes: symbol as primary key; NCBI Gene ID recorded. Duplicate symbols from different sources are merged only when the symbol matches exactly; paralogues are not merged.
- Phenotypes: CID-10 and HPO are many-to-many. Mapping is stored in `data_dictionary/hpo_phenotype_mapping.csv` and in `config.PHENOTYPES`; ambiguous mappings carry `mapping_note`.
- Variants: ClinVar accession; large CNVs (title begins `GRCh`) are excluded because their gene lists are not gene-specific.
- Exposures: class-level nodes; a study measuring NO is mapped to `EXP:NO2` only with an explicit note that the measured species was NO.
- Pathways: Reactome stable ID (`R-HSA-…`), never the display name.

---

## 9. Constraints enforced by code

- Source and target types must belong to the declared vocabulary.
- Relation must be in the declared enumeration.
- Layer must be one of the five values.
- Self-loops are forbidden.
- Curated (`layer = observed`) edges must have a PMID and a verbatim quote verified against PubMed.
- `HYPOTHESIS_LINK` edges must have `evidence_type = hypothesis`.
- Every edge endpoint must exist as a node.
- Evidence IDs must be unique.

These constraints are tested in `tests/test_core.py` and `scripts/validation/01_validate.py`.
